# Parrot Hero

Landing site for Parrot—voice dictation that just works.

## Development

```bash
bun install
bun run dev
```

Runs at [http://localhost:3000](http://localhost:3000).

## Build

```bash
bun run build
bun run preview
```

## Stack

- [TanStack Start](https://tanstack.com/start) (React, Router, Vite)
- [Tailwind CSS 4](https://tailwindcss.com/)
- [Biome](https://biomejs.dev/) for lint and format
